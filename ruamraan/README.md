# รวมร้าน: หลังร้านสำหรับขายผ่านไลฟ์และหลายช่องทาง

ต้นแบบหน้าจอระบบหลังร้านสำหรับแม่ค้าออนไลน์ไทย รวมการขายผ่านไลฟ์ (CF) แชต Facebook/IG/LINE และร้าน Shopee, Lazada, TikTok Shop ไว้ในที่เดียว
ใช้ Vue 3 + Element Plus และออกแบบด้วยอัตลักษณ์ของรวมร้านเอง: สีเขียวหัวเป็ด ฟอนต์ Inter + Noto Sans Thai แถบเมนูเข้ม และมีโหมดมืด
เราศึกษาระบบของคู่แข่งเพื่อเรียนรู้หลักการเท่านั้น ไม่ได้ลอกหน้าตาหรือข้อความ (ดู `design-skill/references/design-system.md` ส่วนที่ 3)

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `app/index.html` | ต้นแบบที่กดใช้ได้ เปิดในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Vue, Element Plus และฟอนต์) |
| `app/src.html` | ซอร์สที่ใช้แก้ไข |
| `app/build.py` | ฝัง stylesheet ของ Element Plus (สว่างและมืด) ลงใน `src.html` แล้วเขียนเป็น `index.html` |
| `design-skill/` | สกิลออกแบบสำหรับ Claude: `SKILL.md` + เอกสารอ้างอิง 3 ไฟล์ |
| `docs/facebook-live-oms-mvp.md` | สเปก MVP: ไลฟ์ Facebook → ออเดอร์ (OMS) → จัดส่งแบบเปิดกว้าง สถาปัตยกรรม โครงข้อมูล แผนงาน ความเสี่ยง |
| `docs/carrier-partner-api.md` | ร่าง API ให้บริษัทขนส่งเชื่อมเข้ามาเป็นพาร์ทเนอร์ |

## สร้าง `index.html` ใหม่หลังแก้ `src.html`

```bash
npm pack element-plus@2.7.3
tar xzf element-plus-2.7.3.tgz package/dist/index.css package/theme-chalk/dark/css-vars.css
python3 app/build.py package/dist/index.css package/theme-chalk/dark/css-vars.css
```

## หน้าจอ

- **ขาย:** หน้าหลัก (แดชบอร์ด), ไลฟ์ขาย, ออเดอร์ (แท็บสถานะ ตัวกรองแบบชิป แผงรายละเอียด สร้างออเดอร์), กล่องข้อความ
- **ข้อมูล:** สินค้า, ลูกค้า, ดรอปชิป
- **วิเคราะห์และตั้งค่า:** รายงาน, ตั้งค่า (ช่องทางขาย · ไลฟ์และคอมเมนต์ · การจัดส่ง · รับเงิน · ข้อความอัตโนมัติ · ตอบกลับอัตโนมัติ · ทีมงาน)
- **ฝั่งลูกค้า:** หน้าลิงก์ชำระเงินบนมือถือ
- **ทั้งแอป:** ค้นหารวมด้วย Ctrl/⌘K และสลับธีมสว่าง/มืด

ทุกหน้าใช้ข้อมูลตัวอย่างในเบราว์เซอร์ ยังไม่มีระบบหลังบ้านและยังไม่ได้เชื่อมแพลตฟอร์มจริง

## เทคโนโลยีที่แนะนำสำหรับสร้างจริง

- **หน้าบ้าน:** Vue 3 + TypeScript + Element Plus (ปรับธีมด้วยตัวแปร CSS)
- **หลังบ้าน:** NestJS หรือ Go แยกโมดูล: ออเดอร์ สินค้า/สต็อก แชต/ไลฟ์ เชื่อมช่องทาง ดรอปชิป รายงาน
- **ข้อมูล:** PostgreSQL + Redis (ล็อกสต็อกตอนจับ CF) + คิวงานสำหรับ webhook และการซิงก์
- **Real-time:** WebSocket สำหรับคอมเมนต์ไลฟ์ แชต และออเดอร์ใหม่
