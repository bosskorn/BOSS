# รวมร้าน: หลังร้านสำหรับขายผ่านไลฟ์และหลายช่องทาง

ต้นแบบหน้าจอระบบหลังร้านสำหรับแม่ค้าออนไลน์ไทย รวมการขายผ่านไลฟ์ (CF) แชต Facebook/IG/LINE และร้าน Shopee, Lazada, TikTok Shop ไว้ในที่เดียว
หน้าตาออกแบบตามระบบออกแบบที่วัดจากเว็บไซต์ระบบหลังร้านต้นแบบ (Vue 3 + Element Plus) ส่วนชื่อ "รวมร้าน" เป็นชื่อชั่วคราว

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `prototype/index.html` | ต้นแบบที่กดใช้ได้ เปิดในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Vue และ Element Plus จาก CDN) |
| `prototype/src.html` | ซอร์สที่ใช้แก้ไข (ยังไม่ได้ฝัง stylesheet ของ Element Plus) |
| `prototype/build.py` | ฝัง stylesheet ของ Element Plus ลงใน `src.html` แล้วเขียนเป็น `index.html` |
| `design-skill/` | สกิลออกแบบสำหรับ Claude: `SKILL.md` + เอกสารอ้างอิง 3 ไฟล์ |
| `design-skill/references/design-system.md` | ระบบออกแบบที่วัดจากเว็บต้นแบบ (สี ฟอนต์ ขนาด โครงหน้า ตาราง) |
| `design-skill/references/screens.md` | สเปกแต่ละหน้าจอ |
| `design-skill/references/domain.md` | กติกาธุรกิจ: สถานะออเดอร์ กติกา CF ตัวแปรข้อความ โครงข้อมูล |

## สร้าง `index.html` ใหม่หลังแก้ `src.html`

```bash
npm pack element-plus@2.7.3
tar xzf element-plus-2.7.3.tgz package/dist/index.css
python3 prototype/build.py package/dist/index.css
```

## หน้าจอในต้นแบบ

- **ภาพรวม:** หน้าหลัก (ทางลัด)
- **ขาย:** ไลฟ์ (จับออเดอร์จากคอมเมนต์), ออเดอร์ (ตัวกรอง แถบเครื่องมือ ตารางออเดอร์ ลิ้นชักรายละเอียดและสร้างออเดอร์)
- **ตัวแทนจำหน่าย:** รายชื่อตัวแทน, ออเดอร์ซัพพลายเออร์
- **สินค้าและลูกค้า:** สินค้า (ตาราง ฟอร์มเพิ่มและแก้ไข), แชตรวม, ลูกค้า
- **รายงาน:** ยอดขาย, สถิติรอบไลฟ์
- **ตั้งค่า:** เชื่อมบัญชี, ตั้งค่าไลฟ์, ขนส่งและค่าส่ง, วิธีชำระเงิน, เทมเพลตข้อความ, ตอบอัตโนมัติ, จัดการผู้ใช้
- **ฝั่งลูกค้า:** ลิงก์ออเดอร์บนมือถือ

ทุกหน้าใช้ข้อมูลตัวอย่างในเบราว์เซอร์ ยังไม่มีระบบหลังบ้าน (API, ฐานข้อมูล) และยังไม่ได้เชื่อมแพลตฟอร์มจริง

## ส่วนที่ยังไม่ได้ศึกษาจากเว็บต้นแบบ

ส่วนเหล่านี้ทดสอบในบัญชีทดลองไม่ได้ เพราะต้องเชื่อมบัญชีภายนอกจริง จึงออกแบบเองโดยใช้ระบบออกแบบเดียวกัน:

- หน้าคุมไลฟ์และการจับ CF จริง (ต้องเชื่อมเพจ Facebook)
- แชตกับลูกค้าจริง
- ซิงก์ออเดอร์และสต็อกกับ marketplace
- ขั้นตอนหลังชำระเงิน: จัดขนส่ง พิมพ์ใบปะหน้า
- หน้าลิงก์ออเดอร์ฝั่งลูกค้า

## เทคโนโลยีที่แนะนำสำหรับสร้างจริง

- **หน้าบ้าน:** Vue 3 + TypeScript + Element Plus (ชุดเดียวกับต้นแบบ) เป็นแอปเดียว ไม่ใช้ iframe
- **หลังบ้าน:** NestJS หรือ Go แยกโมดูล: ออเดอร์ สินค้า/สต็อก แชต/ไลฟ์ เชื่อมช่องทาง ตัวแทน รายงาน
- **ข้อมูล:** PostgreSQL + Redis (ล็อกสต็อกตอนจับ CF) + คิวงานสำหรับ webhook และการซิงก์
- **Real-time:** WebSocket สำหรับคอมเมนต์ไลฟ์ แชต และออเดอร์ใหม่
