# Live Commerce Design — ระบบออกแบบแพลตฟอร์มหลังร้านของเรา

สกิลนี้คือ "คู่มือออกแบบ" ของแพลตฟอร์มหลังร้านสำหรับแม่ค้าออนไลน์ไทย
ฟังก์ชันอ้างอิงจากการสำรวจคู่แข่ง (เครื่องมือผู้ช่วยไลฟ์ + ERP แบบรวมช่องทาง)
แต่ **หน้าตา โครงสร้าง และถ้อยคำเป็นของเราเอง** เป้าหมายคือเก็บ "สิ่งที่เขาทำได้" แล้วแก้ "สิ่งที่เขาทำได้ไม่ดี"

## ใช้สกิลนี้อย่างไร

1. อ่าน `references/design-system.md` (ระบบออกแบบที่วัดจากเว็บไซต์ต้นแบบ) ทุกครั้งก่อนออกแบบ
2. อ่าน `references/screens.md` เฉพาะหัวข้อของหน้าที่กำลังทำ เพื่อดูว่าหน้านั้นมีอะไรบ้าง
3. ถ้างานแตะกติกาธุรกิจ (สถานะออเดอร์ กติกา CF ตัวแปรข้อความ โครงข้อมูล) อ่าน `references/domain.md`
4. สร้างงาน แล้วตรวจกับ "เช็กลิสต์ก่อนส่ง" ท้ายไฟล์

ถ้าผู้ใช้ให้ชื่อแบรนด์หรือโลโก้ ให้เปลี่ยนเฉพาะชื่อและโลโก้ ส่วนระบบออกแบบคงตามต้นแบบ

## ผู้ใช้ของเราคือใคร

- **เจ้าของร้าน/แม่ค้าไลฟ์** ใช้มือถือเป็นหลัก มักทำหลายอย่างพร้อมกันระหว่างไลฟ์ ต้องเห็นของสำคัญในจอเดียวและกดน้อยที่สุด
- **แอดมินตอบแชต/ปิดการขาย** นั่งหน้าคอม ทำงานซ้ำ ๆ ปริมาณมาก ต้องการคีย์ลัด การทำทีละหลายรายการ และตัวกรองที่จำค่าได้
- **ทีมแพ็ก/คลัง** ต้องการรายการที่พิมพ์ได้ สแกนได้ และสถานะที่ชัดว่าใบไหนพร้อมส่ง
- **ลูกค้าปลายทาง** เปิดลิงก์ออเดอร์จากแชตบนมือถือ ไม่มีบัญชี ไม่อยากอ่านเยอะ ต้องจ่ายเงินให้จบใน 1 นาที

ทุกการตัดสินใจด้านดีไซน์ให้ย้อนกลับมาถามว่า "คนไหนในสี่คนนี้ใช้หน้านี้ และเขากำลังรีบทำอะไร"

## ระบบออกแบบ: ใช้ของเว็บไซต์ต้นแบบ

หน้าตาทั้งหมดต้องตามระบบออกแบบที่วัดจากเว็บไซต์ต้นแบบใน `references/design-system.md` **อ่านไฟล์นั้นก่อนออกแบบทุกครั้ง** แล้วใช้ค่าตามนั้นตรง ๆ
อย่าใช้รสนิยมการออกแบบของตัวเอง (การ์ดลอย มุมโค้งใหญ่ เงา สีแบรนด์อื่น เว็บฟอนต์ แถบหัวด้านบน) เพราะผู้ใช้ต้องการหน้าตาแบบระบบหลังร้านมืออาชีพของต้นแบบ

สรุปสั้น:
- **เทคโนโลยีหน้าบ้าน** Vue 3 + Element Plus (แบบเดียวกับต้นแบบ) ปรับธีมด้วยตัวแปร CSS ของ Element Plus
- **ฟอนต์** Helvetica Neue / Arial ของเครื่อง 14px ตารางออเดอร์ 12px
- **สีหลัก** `#0094FF` ตัวเลือกที่เลือกพื้น `#ECF5FF`
- **เมนูซ้าย** 240px พื้น `#F3F3F3` รายการที่เลือกเป็นแถบฟ้าทึบ ไม่มีแถบหัว
- **หน้ารายการ** ตัวกรอง → แถบคั่น 6px → แถบเครื่องมือลิงก์ฟ้า → ตาราง → แบ่งหน้ายึดล่าง
- **ภาษา** ไทย

ส่วนที่ "ปรับเป็นของเรา" ได้: ชื่อและโลโก้ ถ้อยคำภาษาไทย ข้อมูลตัวอย่าง และฟีเจอร์ที่ต้นแบบไม่มี (เช่น หน้าลิงก์ออเดอร์ฝั่งลูกค้า) ซึ่งต้องออกแบบด้วยระบบเดียวกัน

## รูปแบบงานที่ส่ง

- **ขอ mockup/prototype** → หน้า HTML ไฟล์เดียวที่กดดูได้ ใช้ Vue 3 + Element Plus จาก CDN ปรับธีมตาม `design-system.md` ใส่ข้อมูลตัวอย่างแบบร้านไทยจริง และแสดงสภาวะว่างด้วย
- **ขอโค้ดจริง** → Vue 3 + TypeScript + Element Plus แยกคอมโพเนนต์ตามโครงหน้ามาตรฐาน (ตัวกรอง / แถบเครื่องมือ / ตาราง / แบ่งหน้า)
- **ขอสเปก** → ต่อหน้าจอเขียน: เป้าหมาย ข้อมูลที่แสดง ตัวกรอง ปุ่มในแถบเครื่องมือ คอลัมน์ตาราง การกระทำต่อแถว และกติกาธุรกิจ
- **ขอรีวิว UI** → เทียบกับ `design-system.md` ทีละข้อ แล้วเรียงจุดที่ไม่ตรงตามผลกระทบ

## สิ่งที่ไม่ทำ

- ไม่ใช้โลโก้ ชื่อ ภาพประกอบ ไอคอนฟอนต์ หรือไฟล์ของต้นแบบ ระบบออกแบบ (สี ขนาด โครงหน้า) ทำตามต้นแบบได้ แต่วาดและเขียนเอง
- ไม่ใส่ฟีเจอร์ของตลาดอื่นที่ร้านไทยไม่ใช้ (เช่น ใบกำกับภาษีของประเทศอื่น) ถ้าต้องมีให้ซ่อนไว้ตามประเทศของร้าน
- ไม่เติมสไตล์ของตัวเองทับระบบออกแบบของต้นแบบ
