# Live Commerce Design — ระบบออกแบบแพลตฟอร์มหลังร้านของเรา

สกิลนี้คือ "คู่มือออกแบบ" ของแพลตฟอร์มหลังร้านสำหรับแม่ค้าออนไลน์ไทย
เราศึกษาระบบหลังร้านของคู่แข่งเพื่อเรียนรู้ "หลักการ" (ทำไมหน้าจอนั้นใช้งานได้ดี) แต่ **หน้าตา ชื่อ ถ้อยคำ และการจัดวางต้องเป็นของรวมร้านเอง**
เหตุผล: ฟีเจอร์และแนวคิดทั่วไปในวงการ (แท็บสถานะ ตัวกรอง รหัส CF) ใช้ได้ แต่การลอกหน้าตา การจัดวางเฉพาะตัว หรือข้อความของเขามาตรง ๆ เสี่ยงถูกฟ้องและทำให้แบรนด์เราไม่มีตัวตน

## ใช้สกิลนี้อย่างไร

1. อ่าน `references/design-system.md` ทุกครั้งก่อนออกแบบ ไฟล์นี้มี 3 ส่วน: หลักการที่เรียนรู้จากคู่แข่ง · ระบบออกแบบรวมร้าน (ค่าที่ต้องใช้) · เส้นแบ่งสิ่งที่ห้ามลอก
2. อ่าน `references/screens.md` เฉพาะหัวข้อของหน้าที่กำลังทำ และหัวข้อ "ข้อมูลที่ต้องมีครบ" ของหน้านั้นเสมอ เปลี่ยนสไตล์ได้ แต่ห้ามตัดข้อมูลหรือการกระทำ
3. ถ้างานแตะกติกาธุรกิจ (สถานะออเดอร์ กติกา CF ตัวแปรข้อความ โครงข้อมูล) อ่าน `references/domain.md`
4. สร้างงาน แล้วตรวจกับ "เช็กลิสต์ก่อนส่ง" ท้ายไฟล์ โดยเฉพาะข้อ "ไม่เหมือนคู่แข่ง"

## ผู้ใช้ของเราคือใคร

- **เจ้าของร้าน/แม่ค้าไลฟ์** ใช้มือถือเป็นหลัก มักทำหลายอย่างพร้อมกันระหว่างไลฟ์ ต้องเห็นของสำคัญในจอเดียวและกดน้อยที่สุด
- **แอดมินตอบแชต/ปิดการขาย** นั่งหน้าคอม ทำงานซ้ำ ๆ ปริมาณมาก ต้องการคีย์ลัด การทำทีละหลายรายการ และตัวกรองที่จำค่าได้
- **ทีมแพ็ก/คลัง** ต้องการรายการที่พิมพ์ได้ สแกนได้ และสถานะที่ชัดว่าใบไหนพร้อมส่ง
- **ลูกค้าปลายทาง** เปิดลิงก์ออเดอร์จากแชตบนมือถือ ไม่มีบัญชี ไม่อยากอ่านเยอะ ต้องจ่ายเงินให้จบใน 1 นาที

ทุกการตัดสินใจด้านดีไซน์ให้ย้อนกลับมาถามว่า "คนไหนในสี่คนนี้ใช้หน้านี้ และเขากำลังรีบทำอะไร"

## ระบบออกแบบ: ของรวมร้านเอง

ค่าทั้งหมดอยู่ใน `references/design-system.md` ส่วนที่ 2 สรุปสั้น:
- **เทคโนโลยีหน้าบ้าน** Vue 3 + Element Plus (เป็นเทคโนโลยีทั่วไป ใช้ได้) ปรับธีมด้วยตัวแปร CSS ของ Element Plus
- **อัตลักษณ์** สีหลักเขียวหัวเป็ด `#0E9F87` สีไลฟ์ `#FF5A5F` · ฟอนต์ Inter + Noto Sans Thai · มุม 10–14px
- **โครงแอป** แถบเมนูซ้ายสีเข้ม · แถบบนมีค้นหา ⌘K · ทุกหน้ามีหัวหน้า (ชื่อ คำอธิบาย ปุ่มหลัก)
- **หน้ารายการ** การ์ดเดียว: แท็บสถานะแบบเส้นใต้ → แถบตัวกรองแบบชิป → ตาราง → แบ่งหน้า · คลิกแถวเปิดแผงด้านขวา
- **โหมดมืด** มีทุกหน้า
- **ภาษา** ไทย เขียนเองทั้งหมด ไม่แปลจากหน้าจอคู่แข่ง

## รูปแบบงานที่ส่ง

- **ขอ mockup/prototype** → หน้า HTML ไฟล์เดียวที่กดดูได้ ใช้ Vue 3 + Element Plus จาก CDN ตามระบบออกแบบรวมร้าน ใส่ข้อมูลตัวอย่างแบบร้านไทยจริง มีสภาวะว่าง และรองรับโหมดมืด
- **ขอโค้ดจริง** → Vue 3 + TypeScript + Element Plus แยกคอมโพเนนต์: PageHeader, FilterBar (ชิป), StatusTabs, DataTable, DetailPanel, BulkBar
- **ขอสเปก** → ต่อหน้าจอเขียน: เป้าหมาย ข้อมูลที่แสดง ตัวกรอง การกระทำหลัก คอลัมน์ การกระทำต่อแถว และกติกาธุรกิจ
- **ขอรีวิว UI** → เทียบกับระบบออกแบบรวมร้าน และตรวจ "เส้นแบ่ง" ว่ามีส่วนไหนเหมือนคู่แข่งเกินไป

## สิ่งที่ไม่ทำ

- ไม่ลอกหน้าตา การจัดวางเฉพาะตัว สี ฟอนต์ ข้อความ โลโก้ ไอคอน หรือภาพของคู่แข่ง (รายการละเอียดอยู่ใน `design-system.md` ส่วนที่ 3)
- ไม่แปลข้อความจากหน้าจอคู่แข่งมาใช้ ให้เขียนใหม่ด้วยคำของเรา
- ไม่ใส่ฟีเจอร์ของตลาดอื่นที่ร้านไทยไม่ใช้
- ไม่ให้คำแนะนำทางกฎหมาย ถ้าผู้ใช้กังวลเรื่องลิขสิทธิ์หรือเครื่องหมายการค้า แนะนำให้ปรึกษาทนาย

- [ ] **ไม่เหมือนคู่แข่ง:** ผ่านทุกข้อใน `design-system.md` ส่วนที่ 3

## เมื่อศึกษาเว็บตัวอย่าง

บันทึกทุกสิ่งที่พบเป็น 3 ช่อง:
1. สิ่งที่พบ (เขียนด้วยคำของเรา)
2. ระบบเรามีหรือยัง
3. จะทำเมื่อไร หรือทำต่างอย่างไร

แล้วอัปเดต `docs/product-overview.md` (ส่วนสถานะและแผน) ทุกครั้ง ห้ามคัดลอกข้อความหรือรูปของเว็บตัวอย่าง
