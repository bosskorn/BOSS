# ระบบออกแบบ (วัดจากเว็บไซต์ต้นแบบ)

ค่าทุกตัวในไฟล์นี้วัดจาก computed style ของหน้าจอจริงในเว็บต้นแบบ (ระบบหลังร้านแบบ Vue 3 + Element Plus) เมื่อ 16 พ.ย. 2026
ใช้ค่าตามนี้ตรง ๆ อย่าเติมสไตล์ของตัวเอง (การ์ดลอย มุมโค้งใหญ่ เงา gradient สีแบรนด์อื่น) ถ้าค่าไหนไม่ได้วัดไว้ ให้เขียนกำกับว่า "ค่าของเรา"

## ตัวอักษร

| ใช้ที่ | ค่า |
|---|---|
| ฟอนต์ | `"Helvetica Neue", "San Francisco", PingFang, Arial, "Microsoft YaHei"` + ฟอนต์ไทยของเครื่อง (`Thonburi, "Leelawadee UI", Tahoma`) — ไม่โหลดเว็บฟอนต์ |
| ขนาดหลัก | 14px |
| ตารางออเดอร์ | 12px (SKU 13px หนา 600) |
| แบ่งหน้า (ทั้งหมด / ขนาดหน้า) | 12px |
| หัวข้อส่วนในหน้ารายละเอียด | 13px หนา 700 สี `#101010` |
| หัว dialog | 16px หนา 700 สี `#303133` |
| น้ำหนักหัวตาราง | 400 (ไม่หนา) |

## โครงแอป

- **เมนูซ้าย** กว้าง 240px พื้น `#F3F3F3` ส่วนบน 118px มีโลโก้ (ไอคอน 42px + ชื่อ) และชื่อผู้ใช้สี `#666` 14px ตามด้วยลูกศร `#CCC`
- **รายการเมนู** สูง 40px padding 0 10px ไอคอน 16px ในกล่อง 40×32 ตัวอักษร 14px สีดำ
- **เมนูที่เลือก** พื้น `#0094FF` ตัวอักษรและไอคอนสีขาว เต็มความกว้าง ไม่มีมุมโค้ง
- **เมนูมีลูก** กดแล้วขยายรายการย่อยด้านล่าง รายการย่อยไม่มีไอคอน
- **ล่างสุด** ลิงก์ "ติดต่อฝ่ายบริการลูกค้า" สี primary พร้อมไอคอนหูฟัง 20px
- **ไม่มีแถบหัวด้านบน** เนื้อหาเต็มพื้นที่ที่เหลือ พื้นขาว

## หน้ารายการ (โครงมาตรฐาน)

บนลงล่าง:
1. **ฟอร์มตัวกรอง** padding 10px 10px 5px
   - แถวตัวเลือก สูง 28px ห่างกัน 2px ป้ายกว้าง 130px ชิดขวา สี `#999` padding-right 12px
   - ตัวเลือก: ปุ่มเล็กสูง 24px padding 5px 11px มุม 3px ห่างกัน 10px ตัวอักษรดำ ไม่มีพื้น
   - ตัวเลือกที่ถูกเลือก: พื้น `#ECF5FF` ตัวอักษร `#0094FF`
   - ตัวเลขในวงเล็บสีแดง เช่น `รอชำระ(2)`
   - แถวช่องกรอก สูง 32px: ปุ่มกลุ่ม (ขาว ขอบ `#DCDFE6` ตัวที่เลือก พื้น `#ECF5FF` ขอบ `#C6E2FF` ตัวอักษร primary) + ช่องกรอก/ช่องวันที่ + ปุ่มลัด เมื่อวาน / วันนี้ / 7 วัน / 15 วัน
   - ช่องค้นหาด่วน: ปุ่มกลุ่มเลือกประเภท (เลขออเดอร์ / เลขพัสดุ / ...) ติดกับช่องกรอก
   - ปุ่ม: "ค้นหา" พื้น primary ทึบ + ไอคอนแว่นขยาย (บางหน้าใช้แบบอ่อน พื้น `#E6F4FF` ตัวอักษร primary) · "ล้าง" พื้น `#EEE` ตัวอักษร `#606266` · "บันทึกเงื่อนไขกรอง" ลิงก์ 12px + ไอคอนเฟือง
2. **แถบคั่น** เส้นล่าง 6px `#F3F3F3`
3. **แถบเครื่องมือ** สูง 44px padding 6px 6px 6px 10px
   - ปุ่มข้อความสี primary 14px + ไอคอนนำหน้า บางตัวมีลูกศร dropdown ห่างกัน 10–18px
   - ปุ่มที่ใช้ไม่ได้เป็นสีเทา
   - ขวาสุด: "เลือก 0 รายการ" · ไอคอนตั้งค่าคอลัมน์ / ส่งออก / รีเฟรช สี primary
4. **ตาราง**
   - หัว 40px พื้น `#FCFCFC` ตัวอักษร `#444` 14px น้ำหนัก 400 มีเส้นคั่นสั้นสี `#DCDFE6` ระหว่างคอลัมน์ เส้นล่าง 1px
   - แถว 53px พื้นขาว **ไม่มีเส้นคั่นแถว** padding cell 0 10px
   - คอลัมน์แรกเป็นลำดับ (40px) ถัดมาเป็นช่องเลือก
   - รูปสินค้า 32px พื้นฟ้าอ่อน
   - คอลัมน์ "จัดการ" อยู่ขวา (fixed) เป็นไอคอนสี primary (แก้ไข ลบ) หรือลิงก์ข้อความสี primary
5. **แบ่งหน้า** ยึดล่างจอ เส้นบน 1px
   - ชิดขวา: "เลือก 0 รายการ" (14px) · "ทั้งหมด 1" (12px) · ขนาดหน้า "20/หน้า" กว้าง 110px · ‹ หน้า › · "ไปที่ [1]"
   - บางหน้าใช้รูปแบบ "แสดงต่อหน้า [10] ทั้งหมด 1 แถว 1/1 หน้า |‹ ‹ › ›|"

หน้าว่างใช้ไอคอนกล่องเส้นสีเทาตรงกลางพร้อมข้อความ "ไม่มีข้อมูล" สีเทา

## ตารางออเดอร์ (รูปแบบเฉพาะ)

- **หัว** สูง 36px พื้น `#FCFCFC` ตัวอักษร `#101010` 14px
  - คอลัมน์: ข้อมูลสินค้า · ยอดเงิน · ป้าย/หมายเหตุ · คลัง · ข้อมูลขนส่ง · ข้อมูลจัดส่ง · เวลา
- **แต่ละออเดอร์** มีขอบ 1px `#F2F0F0`
  - แถบซ้าย 3px สีตามสถานะ
  - ตัวอักษร 12px
- **แถบหัวของออเดอร์** สูง 32px เส้นล่าง `#F3F6FE` เรียงตามนี้:
  - ช่องเลือก
  - จุดสถานะ 8px (วงรอบสี 12%) + ชื่อสถานะ
  - เวลา (หนา)
  - ไอคอนเอกสาร + เลขออเดอร์ (`#2979FF`)
  - ไอคอนแชต + ชื่อผู้ซื้อ (`#2979FF`)
  - ไอคอนร้าน + ชื่อร้าน (หนา สี primary)
  - ชื่อผู้ดูแล
  - ขวาสุด: ลิงก์การกระทำ 14px สี `#528FFF` คั่นด้วย " - " เช่น "แก้สลิป - อัปโหลดสลิป - คืนเงิน"
- **ส่วนเนื้อ**
  - สินค้า: รูป 40px + ชื่อ + ราคา + `× จำนวน` สีแดง แถวล่างเป็น SKU หนา 13px + รหัสสินค้าสีเทา
  - ยอดเงิน: `฿199` / ค่าส่ง: 0 / ส่วนลด: 0 เรียงลงล่าง
  - ป้าย: el-tag พื้น `#ECF5FF` ขอบ `#D9ECFF` ตัวอักษร primary 12px สูง 20px
  - คอลัมน์ที่เหลือเป็นข้อความธรรมดา

## หน้ารายละเอียด / แก้ไขออเดอร์ (เปิดเป็นลิ้นชักด้านขวา)

- **แท็บบนสุด** พร้อมไอคอน: ออเดอร์ · การชำระเงิน · ประวัติ แท็บที่เลือกสี primary มีเส้นใต้
- **"ข้อมูลพื้นฐาน"** เป็นตาราง 3 คอลัมน์
  - แถวป้าย: พื้น `#FAFAFA` ตัวอักษร `#999` 13px
  - แถวค่า: พื้นขาว
  - เส้นขอบ `#EBEEF5`
- **"ข้อมูลสินค้า"** มีลิงก์ "+ เพิ่มสินค้า · + เพิ่มของแถม · นำเข้าสินค้า" และช่องค้นหา ตามด้วยตารางสินค้าแบบมาตรฐาน
- **สรุปยอด** ชิดขวา: ป้ายตามด้วยค่า ยอดเงินสีแดง `฿ 199` (รวม / ชำระแล้ว / ค้างชำระ / ยอดคืน) ปุ่ม "คำนวณใหม่" พื้น primary เล็ก
- **ล่างสุดยึดติด** ปุ่ม รีเฟรช · คืนเงิน (ขาวมีขอบ) · บันทึก (primary)

## หน้าตั้งค่า

- **พื้นหน้า** `#EEE` padding 10px
- **แผงขาว** กว้าง 740px มุม 3px padding 0 15px
- **แต่ละรายการ** หัวข้อ 14px `#333` คำอธิบายใต้หัวข้อสี `#A3A3A3` 14px (margin-top 8px) ตัวควบคุมชิดขวา เส้นคั่นบาง ๆ
- **ตัวควบคุม**
  - สวิตช์ 40×20 ปิด = `#DCDFE6`
  - ช่องเลือก 180×32
  - ช่องกรอกเล็ก 186×24 ขอบ `#CCC`
- **ฟอร์มย่อย** (ข้อมูลผู้ส่ง) ป้ายมีดอกจันแดง ช่องกรอกกว้างทางขวา

## รายงาน

- **หัวข้อส่วน** เช่น "ภาพรวม" 14px padding 10px เส้นล่าง 1px `#DCDFE6`
- **การ์ดตัวเลข** 7 ใบเรียงแถว ขนาดราว 180×110 พื้นเทาอ่อน มุม 6px
  - ไอคอนวงกลมสีทึบ 30px ที่มุมซ้ายบน แต่ละใบสีต่างกัน: ฟ้าอมเขียว ส้ม เขียว ส้ม เหลือง เขียวอ่อน น้ำเงิน
  - ชื่อตัวชี้วัดสีเทา 16px
- **แท็บมุมมอง** (ตามร้าน / ตามวัน / ตามเดือน) เป็นปุ่มกลุ่ม ตัวที่เลือกพื้น primary ทึบ
- **ตาราง** หัวคอลัมน์มีลูกศรเรียงลำดับและไอคอน (?) อธิบาย

## แชต

- **คอลัมน์รายการ** ราว 250px
  - บนสุด: ตัวเลือกประเภทค้นหา + ช่องค้นหา + "…"
  - ถัดมา: ตัวกรองข้อความ "บัญชี · ประเภทข้อความ · ป้าย"
- **แต่ละห้อง** ชื่อสี `#043450` 14px เวลาสี `#8C9EA8` 12px จุดแดงเมื่อยังไม่อ่าน
- **พื้นที่ข้อความ** พื้นเทา padding 20px
  - การ์ดข้อความพื้นขาว padding 10px 24px
  - เวลาเหนือการ์ด 12px `#666`

## หน้าหลัก

- หัวข้อ "รวมร้าน | ทางลัด" (ชื่อดำหนา + ส่วนหลังสี primary 18px)

  - ไอคอนเส้น 48px ตรงกลาง

## สิ่งที่ห้ามทำ

- **ห้ามการ์ดลอย** ไม่มีเงาหรือมุมโค้งใหญ่ในหน้ารายการ ยกเว้นการ์ดทางลัดหน้าหลักและการ์ดตัวเลขรายงาน
- **ห้ามแถบหัวด้านบน**
- **ห้ามหัวตารางตัวหนา** และห้ามเส้นคั่นแถวในตารางมาตรฐาน
- **ห้ามเว็บฟอนต์** และห้ามสีหลักอื่นนอกจาก `#0094FF`
